## 0. H3 결정 (2026-10-17, PRD 작성자)
- **조건부 인수 승인.** 현재 구현은 **로컬 PC 시험 운영 모드**로 사용 가능하다. **실제 고객 대상 운영과 실결제 활성화는 승인하지 않는다.**
- 추가 검증 조건(RTM 2-5): **C-1** 실제 Google Forms·AI API 연동 시험 · **C-2** 아버님 사용성 시험 · **C-3** 실제 자택 PC 재부팅·복구 시험 · **C-4** 조건부 충족 11개 항목의 시험 증빙 확인 · **C-5** 스마트스토어 실결제·소비자 계약 정책 검증.
- 운영 규칙: C-1~C-5가 끝나기 전에는 설정 → Gate에서 GATE-OPS-01·LEGAL-01·SS-02를 통과로 기록하지 않는다(기록하지 않는 한 앱은 시험 운영 모드 — 결제·견적 “시험” 표지, 실거래 결제 요청 차단).
- 로컬 전용 구현(SRS-145)과 **모바일 원격 관리자 사용(SRS-171)을 분리**해 후자를 **미완료 기능**으로 추적한다(아래 표 REMOTE-ADMIN 행).
- H1 수정 승인 3건(Q2·Q9·Q10)은 구현·회귀 시험까지 반영했다(14_TR §8, 179 PASS).

틴틴골드 OS 개인정보처리방침

시행일: 2026년 10월 24일

1. 프로그램 소개

틴틴골드 OS(이하 "프로그램")는 주얼리 공방 틴틴골드가 내부 업무용으로 쓰는 주문 관리 프로그램입니다. 프로그램은 공방 PC에서만 실행되며 외부 서버를 두지 않습니다.

2. Google 계정에서 사용하는 정보

프로그램은 틴틴골드의 Google 계정에 연결해 다음 권한만 읽기 전용으로 사용합니다.

  • Google 설문지 응답 보기(forms.responses.readonly): 고객이 틴틴골드 의뢰 설문지에 제출한 응답을 불러옵니다.
  • Google Drive 파일 보기(drive.readonly): 고객이 설문지에 첨부한 참고 사진을 내려받습니다.

프로그램은 Google 계정의 데이터를 수정하거나 삭제하지 않으며, 위 용도 외에는 사용하지 않습니다.

3. 수집하는 고객 정보

고객이 설문지에 직접 입력한 이름, 연락처, 의뢰 내용, 첨부 사진을 주문 처리와 고객 응대에만 사용합니다.

4. 보관과 보호

  • 정보는 공방 PC에만 저장되며, 연락처 등 민감한 항목은 암호화해 보관합니다.
  • 백업 파일도 암호화되며 공방이 관리하는 저장 장치에만 둡니다.
  • 정보를 제3자에게 판매하거나 제공하지 않습니다. 광고에 사용하지 않습니다.

5. Google 사용자 데이터 정책 준수

프로그램이 Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

6. 연결 해제와 삭제 요청

Google 연결은 언제든 Google 계정 → 타사 앱 및 서비스에서 해제할 수 있습니다. 본인 정보의 열람·정정·삭제를 원하시면 아래 이메일로 요청해 주세요. 확인 후 지체 없이 처리합니다.

# P4 최도윤(가상) — R2 취소·환불 여정 최종 평가

여정: Form A(10/25) → 접수 확인 카톡 → 상한 초과 예외(운영자)·수락 → 시안·견적 250,000원 → Form B 동의(공용 계정 경고 → 운영자 확인) → 예약금 83,334원(흉내) → 10/29 단순 변심 취소(CAD 10/31 시작 전) → R2 전액 환불·주문 취소.

## 고객 최종 평가 — 추천 8/10, 재의뢰 의향 있음
좋았던 점
1. 절차가 처음부터 끝까지 한 줄로 이어짐(시안·견적 → 동의·예약금 1/3 → CAD → 잔금 2/3 → 제작 약 2주).
2. 단계별 환불 규정이 명시되고 실제로도 문서대로 공제 없이 처리됨 — "문서와 현실이 같다"가 가장 큰 신뢰 요인.
3. 응답이 빠르고 구체적(결제 위치·관리코드·CAD 시작일·시작 당일 알림 약속).

불편했던 점
1. "상세 CAD 착수"의 기준이 문서에 없음 — 환불 구간을 고객이 스스로 판단할 수 없음.
2. 문서 미완성 표시와 불일치("시험 견적", [TBD-002], ○○○ 빈칸, 결제처 안내가 견적서·Form B에서 다름, 발행일, 환불 기한 "3영업일"(⑥) vs "3~5영업일"(카톡)).
3. Form A 예시가 반지 위주, Form B Google 로그인과 법령 인용이 일반 고객에게 부담.

## 앱에서 확인된 것
- R2 자동 분류·자동 금액(83,334원), 법적 검토 불필요 표시, 3영업일 기한(결정 후 표시) — 정상.
- **문제**: 환불 완료 후에도 CAD 시작이 막히지 않음(S-32), 환불·취소·결제 역분개 3중 입력(S-33).

# 카카오톡 채널 연결 절차 (틴틴골드)

> 전제: 카카오톡 채널은 만들어 둔 상태 — 채널 URL `http://pf.kakao.com/_dxhAWX`, 채팅 URL `http://pf.kakao.com/_dxhAWX/chat`(앱에는 https로 등록, D-27). Jewelry OS는 지금(R1) 카카오와 **자동 연동하지 않는다**(ASM-015) — 상담 내용 기록·답변 승인·발송 기록은 앱에서, 실제 대화는 채널 관리자 앱/PC에서 사람이 한다. 자동 연동(챗봇·알림톡·상담톡)은 GATE-CS-01(공급업체 계약) 뒤의 일이다.
> 카카오 화면 메뉴 이름은 바뀔 수 있다 — 아래는 할 일 기준이고, 정확한 메뉴는 카카오 비즈니스 관리자센터(business.kakao.com)에서 확인한다.

## 1. 채널 기본 설정 (카카오 비즈니스 관리자센터)

| # | 할 일 | 이유 |

| 1 | **프로필**: 채널 이름 `틴틴골드`, 프로필 사진(TN 로고), 소개 문구(맞춤 주얼리 제작 상담), 운영 시간 | 견적서·Form B·고객 안내에서 같은 이름·로고로 보이게 |

| 4 | **채널 URL·채팅 URL 확보**(`pf.kakao.com/_…`, 채팅은 그 뒤 `/chat`) | 폼·견적서·스마트스토어에 넣을 주소 |
| 5 | **관리자 추가**: 운영자(필수), 아버님(선택) — 개인 카카오 계정으로 초대 | 한 사람 휴대폰에만 묶이지 않게 |
| 6 | **자동응답**: 첫 인사(웰컴) — “맞춤 제작 문의는 아래 문의 폼(Form A)으로 남겨 주세요 + Form A 링크”, 상담 시간 밖 안내 | 문의를 Form A로 모아 앱에 자동 접수 |
| 7 | (선택) **비즈니스 인증**(사업자등록증) | 검색 노출·신뢰 표시, 나중에 알림톡을 쓰려면 필요 |

## 2. 고객이 채널을 만나는 곳에 링크 넣기

| 위치 | 넣을 것 |
|---|---|
| Form A(문의 폼) 설명 | ✓ 등록됨(2026-10-24 forms.get 확인: “▶ 틴틴골드 카카오톡 상담하기” + 채팅 링크, 연락 방법 선택지 ‘카카오톡 채널’). 제출 완료 메시지는 API로 읽을 수 없어 확인 못 함 |
| Form B(계약 동의) 03-1 환불 안내 ⑥ | 링크 없음 — “틴틴골드가 안내한 카카오톡 등 고객지원 채널” 문구(채널은 견적서·카톡으로 안내되므로 그대로 둬도 됨). 바꾸면 고지 버전이 바뀌어 발행된 계약 링크는 재발행 대상 |
| 견적서(고객 안내 문서) 하단 · 카톡용 텍스트 | ✓ 앱이 자동 표시(견적서 = 채널 링크, 카톡용 텍스트 = 채팅 링크) — D-27 |
| 스마트스토어 상품 페이지·인스타그램 프로필 | 채널 링크 |

## 3. 앱에서의 하루 흐름 (지금 방식 그대로)

1. 카카오로 문의가 오면 → Form A 링크를 보내 접수(폼 밖 전화·카톡 의뢰는 앱 **수기 접수**, 동의 증빙 필수).
2. 상담 대화 → 채널 관리자 앱·PC에서 대화를 **복사**(또는 ‘대화 내보내기’ .txt) → 주문 › **상담** 탭 ‘카카오톡 대화 붙여넣기’(주문 전이면 상담함 › ‘주문 전 문의’) → 메시지별로 자동 기록(D-30) → 아버님은 앱에서 대화를 읽고 AI 초안 승인 → 운영자가 **복사**해서 채널 채팅에 보내기 → **발송 기록**. 하루 1~2번 몰아서 붙여도 중복 없이 새 메시지만 들어간다.
3. 견적 확정 → 주문 › 시안·견적 › **계약 동의 링크 생성 → 링크 복사** → 채널 채팅으로 전송 → **고객에게 보냄 기록**(채널: 카카오톡, 가능하면 전송 화면 캡처).
4. Form B 제출 뒤 본인 확인: 그 링크를 받은 **채널 채팅 상대가 제출했는지** 확인 → 확인 방법 “확인된 상담 채널(카카오톡)”으로 검증.
5. 최종 CAD 승인·취소·환불·A/S 요청도 채널로 받고, 앱에 기록(최종 시안 동의 증빙, 취소·환불 요청 접수).

같은 사람인지: Form A의 이름·전화번호가 같으면 앱이 자동으로 같은 고객으로 묶는다(D-26). 카카오 채팅 상대 이름과 Form A 이름이 다르면 운영자가 고객 화면에서 직접 연결한다.

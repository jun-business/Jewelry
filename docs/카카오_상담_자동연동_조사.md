# 카카오톡 상담 자동 연동 — 방법·비용·업체·외부 접속 조사 (2026-10-24)

> 요구사항(사업 책임자): **아버님은 카카오톡 채널을 따로 열지 않고 Jewelry OS로만 상담을 본다.** → 고객 카톡 메시지가 앱 상담 메뉴에 자동으로 들어오고, 앱에서 승인한 답이 고객 카톡으로 나가야 한다.
> 출처는 공개 웹 자료(딜러사·채널톡 공식 도움말·블로그)이며 가격은 바뀔 수 있다 — **계약 전 견적·약관으로 다시 확인**. “미확인”은 공개 자료로 확인하지 못한 항목.

## 1. 기본 사실

- **카카오톡 채널 1:1 채팅**은 무료지만, 그 대화를 외부 프로그램이 읽어 오는 공개 방법이 없다(관리자센터 앱·PC에서 사람이 봄). 지금 Jewelry OS가 수동 기록인 이유.
- 외부 시스템과 대화를 주고받으려면 **상담톡**(카카오 공식 딜러사를 통해서만 도입하는 별도 상품)을 써야 한다. 상담 솔루션(채널톡·해피톡 등)이 상담톡 위에 상담 화면을 얹는 구조다.
- 상담톡을 켜면 **카카오 채널 관리자센터의 1:1 대화 목록에 더 이상 표시되지 않고**, 상담은 연동한 솔루션에서만 관리한다 → **연동 전 기존 1:1 대화 이력 백업 필요**.
- 챗봇(카카오 i 오픈빌더)은 정해진 시나리오 응답용이고, 우리 쪽 **공개 HTTPS 서버(스킬 서버·도메인·인증서)**가 있어야 한다 — 자유로운 1:1 상담 대체가 아니고 자택 PC 구조와 맞지 않다.

## 2. 방법 비교

| | A. 지금 방식(수동 기록) | **B. 채널톡 상담톡 + 앱이 Open API로 가져오기·보내기(추천)** | C. 다른 상담톡 딜러(해피톡 등) | D. 오픈빌더 챗봇 + 웹훅 |
|---|---|---|---|---|
| 아버님이 앱만으로 상담 | ✗ 운영자가 카톡을 보고 요약해 넣어야 함 | **✓ 고객 메시지가 앱에 들어오고 승인한 답이 앱에서 나감** | ✓/미확인 — 업체별 API 제공 여부 확인 필요 | △ 봇 응답만, 자유 상담 아님 |
| 외부 접속(자택 PC를 인터넷에 여는 일) | 필요 없음 | **필요 없음** — 앱이 몇 분마다 채널톡에 *나가서* 묻는(폴링) 방식. 즉시 알림(웹훅)을 원할 때만 필요 | 업체 방식에 따름 | **필요** — 공개 HTTPS 주소(도메인+인증서, 터널 또는 서버). GATE-REMOTE-01 |
| 비용 | 0원 | 상담톡 **80원/상담**(SaaS 에디션, 같은 고객 24시간 내 재대화는 1회, 하루 = 04:00~익일 03:59), 무료+ 플랜·14일 체험은 **100원 후불**. AI 에디션 크레딧 80원·후불 100원(VAT 별도). 플랜: 얼리 스테이지 **월 36,000원**(연 구독 월 27,000원), 그로스 월 120,000원(연 90,000원), VAT 별도 | 공개 단가 없음 — 월 고정비 + 상담방 과금 구조가 많고 딜러별 견적 | 도메인·서버(호스팅) 비용 + 개발. 카카오 쪽 이용료 미확인 |
| 할 일 | — | 채널톡 가입·카카오 연동(채널 검색용 아이디·관리자 휴대폰 인증), API 키 발급, 앱에 연동 모듈 개발 | 딜러 상담·견적·API 확인 | 서버·도메인·보안, 시나리오 설계 |
| 위험·확인 | 아버님 요구 불충족 | **어느 플랜에서 Open API를 쓸 수 있는지 미확인**(공식 문서에 플랜 조건 없음) — 체험 기간에 확인. 2026-10-16 이후 가격제(AI 에디션) 변경 가능성 | 단가·API 미공개 | 자유 상담 불가 |

예상 비용(B, 참고): 한 달에 고객 30명이 각자 5일씩 대화하면 상담 150건 × 80원 = 12,000원 + 플랜(얼리 스테이지면 36,000원) ≈ **월 5만 원 안팎(VAT 별도)**. 상담이 적으면 무료+ 플랜 후불(100원/상담)도 가능할 수 있음 — Open API 가능 여부 확인 필요.

## 3. 추천안 B — 앱 안에서의 흐름

```
고객 카카오톡 ──(상담톡)──▶ 채널톡 ◀──(Open API, 앱이 몇 분마다 조회·전송)── Jewelry OS(자택 PC)
                                                             └─ 상담 메뉴: 대화 보기 → AI 초안 → 아버님 승인 → 앱에서 바로 발송
```

1. **가져오기**: 앱이 주기적으로(예: 1~5분, Form 동기화처럼) 새 상담·메시지를 받아 상담 메뉴에 표시 — 중복 없이(채널톡 메시지 ID 기준), PC가 꺼져 있던 동안의 대화도 켜면 이어서. 사진 첨부도 파일로 저장.
2. **고객 연결**: 채널톡 고객의 전화번호·이름으로 Jewelry OS 고객·주문에 연결(이름·전화가 같으면 자동, D-26). 주문 전 문의도 상담함에 보관.
3. **답장**: 지금처럼 AI 초안 → 아버님 승인 → **복사 대신 ‘보내기’** 버튼으로 채널톡 API를 통해 고객 카톡에 발송, 발송 기록 자동. 계약 동의 링크·견적 텍스트도 같은 방식으로 보낼 수 있음.
4. **PC가 꺼져 있을 때**: 메시지는 채널톡에 쌓이고 PC를 켜면 들어온다. 그동안 고객에게는 채널톡 자동응답(상담 시간 안내)을 설정. 급할 때는 운영자가 채널톡 모바일 앱으로 응대 가능(아버님은 앱만).
5. **보안**: API 키는 Google 키처럼 PC의 secrets.env와 키 파일에만(코드·GitHub 금지), 고객 메시지는 기존 상담 기록과 같은 방식(연락처 가림)으로 저장.
